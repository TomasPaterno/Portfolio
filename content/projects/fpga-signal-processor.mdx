  en: |
    ## Overview

    This project implements a **fixed-point DSP chain** on Artix-7 for real-time IQ processing. The design prioritizes predictable latency and clean AXI-Stream backpressure handling.

    ## Pipeline stages

    1. **Input FIFO** — elastic buffer from ADC interface
    2. **CORDIC rotator** — phase correction per bin
    3. **FIR decimator** — 4× downsample with symmetric coeffs
    4. **Magnitude estimator** — peak detect for trigger logic

    ## Host integration

    A Python control daemon maps PCIe BAR space for register peek/poke and streams capture buffers to disk for offline analysis.

    ## Lessons learned

    Timing closure at 200 MHz required pipeline retiming on the CORDIC stage. Using `(* use_dsp = "yes" *)` attributes cut LUT pressure significantly.
